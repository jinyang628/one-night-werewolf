# One Night Werewolf — WeChat Mini Program

Native WeChat Mini Program clone of `one_night_werewolf_phone_app`. It shares
the existing FastAPI/Supabase backend and implements:

- English and Simplified Chinese UI
- Pass-and-play setup for 3–8 players
- Custom role composition
- Private role handoff and reveal
- Ordered night actions for every supported role
- Discussion timer, private voting, and results
- Create/join room lobby, host role configuration, and lobby polling
